## The entry

One line a gamer texts the boss to skip work on GTA 6 launch week:

> can't come in tomorrow, gas safety check 9-11, someone has to be home or it's a £60 callout

- **18 words**, 91 characters — inside the 20-word cap and the 1–140 character gate.
- No wild story, no dead grandmother, no flat tyre: just a boring, specific, verifiable-sounding morning window and the real reason anyone stays home — the £60 callout fee.

## How it works

`main.py` (Python 3, standard library only) writes that single line to `/output/entry.txt`, with no trailing newline, so the file holds exactly the text the judge reads.

## Run it

```sh
python3 main.py
```

Then check the output:

```sh
cat /output/entry.txt
```
